# Phuket After Dark — guide 21+

Адаптивный сайт-гайд на Next.js + Tailwind CSS. Включает подбор районов и сценариев вечера, краткие бонусные карточки, безопасность, нативные рекламные слоты, платные предложения и форму обратной связи.

## Локальный запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

Откройте http://localhost:3000. Без настроек Supabase сайт запускается, а API формы вернёт сообщение, что подключение ещё не выполнено.

## Подключение Supabase

1. Выберите активный проект Supabase.
2. Выполните `supabase/migrations/202610260001_create_guide_feedback.sql` в SQL Editor проекта.
3. Заполните `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` в `.env.local`.
4. Перезапустите приложение. Service role key используется только на сервере и никогда не должен попадать в клиентский код или Git.

API `/api/feedback` проверяет поля и длины, использует honeypot против простого спама. Для публичного production-развёртывания рекомендуется добавить rate limiting и CAPTCHA/Turnstile.

## Контент и изображения

Партнёрские ссылки и контакты оставлены обозначенными слотами в `app/page.tsx`. Внешние фотографии подгружаются с Unsplash; перед коммерческим запуском замените их на свои либо на изображения с подходящей лицензией и оптимизируйте локально.
